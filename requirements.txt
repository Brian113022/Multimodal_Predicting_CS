# TotalSegmentator segmentation for the web app's Radiomics VOI.
#
# The torch pin carries the "+cu118" local version on purpose. PyPI's Windows
# torch wheel is CPU-only, and under PEP 440 a plain "torch==2.5.1" is already
# satisfied by an installed "2.5.1+cpu" - so the plain pin installs nothing and
# TotalSegmentator silently falls back to the CPU, which costs minutes per case.
# Naming the local version forces the CUDA wheel from PyTorch's own index.
#
# No NVIDIA GPU? Replace the two pinned lines with matching CPU torch and
# torchvision builds and start the app with TOTALSEGMENTATOR_REQUIRE_GPU=0.
--extra-index-url https://download.pytorch.org/whl/cu118
torch==2.5.1+cu118
torchvision==0.20.1+cu118
